# Colorín Colorado — notes for Claude Code

Streamlit app that turns the user's photos into a printable coloring book: photo → black-and-white
line art (Gemini, or an offline draft) → PDF with the reference photo and a caption box per page,
ready to sell as an Amazon KDP paperback with its wraparound cover. Sibling of `../Once_Upon_a_Time`,
same stack and conventions. Read `README.md` for the product, `docs/architecture.md` for modules and
data layout, `docs/plan.md` for the phases, `docs/amazon-kdp.md` for everything Amazon.

The product is place-neutral: examples in the README, docs, UI placeholders and tests must not
name a country or city (the author's own books can be about anything).

## Conventions

- Code, comments, prompts, docs and commit messages are in English. User-facing text is in Spanish
  and English through `app/core/i18n.py`: never hard-code a UI string; add the key in both languages.
- Business logic goes in `app/core/` and never imports Streamlit; `app/ui/` only calls it and renders.
- Every Gemini call goes through `app/core/gemini.py` and records usage; wrap book work in
  `usage.book_context(book.id)` (by id, not slug).
- Every coloring page an engine returns goes through `lineart.clean` before it is stored or shown.
  Coloring pages are 1-bit; never JPEG-encode line art anywhere (the PDF embeds it losslessly).
  Mystery mosaics (`mosaic.py`) are the one exception: the grid is stored as data
  (`v<n>-raw.png`), drawn as vectors in the PDF (faint gray is impossible in 1 bit), and the
  stored `v<n>.png` is the solution, already 1-bit and not cleaned (cleaning hollows black cells).
- The uploaded photo is always the reference image of a conversion; never draw a page from text.
  Cover art (`cover_art.py`) is the one exception: full color, not cleaned, stored as JPEG, and it
  may be drawn from text.
- Extra pages and activities are generated by `extras.py` from the book's pages, never drawn by the
  AI, and seeded with the book id. The text model (`captions.py`) only translates or describes what
  the book contains; never ask it for facts.
- Per-age settings live in several dicts (`lineart`, `imaging.AGE_PROMPTS`, `extras`, `mosaic`); a new age
  group or style needs an entry in each, and a check on real photos recorded in `docs/spike.md`.
- Versions are append-only (`pages.add_version`, `cover_art`); never overwrite `v<n>.png` or
  `cover_art/v<n>.jpg`. A page version is deleted only when the author asks
  (`pages.delete_version`), and its number is never reused (`Page.last_version`).
- Streamlit widgets fed from saved data: seed the key with `ui.common.seed` and do not pass
  `value=`/`index=`; keep option labels free of data that changes while the user works. See
  "UI rules" in `docs/architecture.md` for why (lost clicks).
- `books/`, `data/`, `spike/` and `config/.env` are user data and git-ignored. Never commit them and
  never put a real GCP project ID or API key in `config/.env.example`.
- Security (see "Security" in `docs/architecture.md`): never seed a widget with a saved secret;
  any new name that becomes part of a path needs a pattern in `schema.py` and a `books.inside`
  check; user text goes through `ui.common.plain` in Markdown and `escape` in ReportLab.
- When changing a model id (`GEMINI_*`), update `config/.env.example`, the defaults in
  `app/core/config.py`, `PRICING` in `app/core/usage.py`, and the table in `docs/setup.md`.
- Amazon KDP numbers (sizes, page ranges, costs, royalties) live in `app/core/kdp.py`, with their
  sources in `docs/amazon-kdp.md`; change them together, and `tests/test_kdp.py`. The interior PDF
  must keep every font embedded and line art at 300 ppi or more.
- Prompt changes: re-run `scripts/spike.py` on the affected cases (`--jobs`), look at the contact
  sheets, and record what changed in `docs/spike.md`. Cleanup changes can be checked for free with
  `--reclean`.

## Running

`docker compose up -d` (port 8502) with `app/`, `tests/` and `scripts/` bind-mounted. Streamlit and
OpenCV are not installed on the host; run tests in the container:

    docker compose run --rm --no-deps app python -m pytest -p no:cacheprovider tests

Streamlit only reloads changed modules while a browser tab is connected; after editing with no tab
open (e.g. between Playwright runs), `docker compose restart app`.

## Skills

`.claude/skills/run-app` starts, stops, tests and debugs the app. Prefer its script over ad-hoc
compose commands.
